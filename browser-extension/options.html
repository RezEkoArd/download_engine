Sertakan Cookie Situs

Diperlukan untuk link yang hanya bisa diunduh setelah login (mencegah HTTP 403)

Mengaktifkannya memberi extension izin membaca semua cookie-mu, termasuk yang HttpOnly — yang normalnya tidak bisa dibaca JavaScript halaman mana pun. Itu kenaikan akses yang nyata, jadi sengaja tidak dijadikan izin wajib.

Cookie hanya dibaca saat sebuah link dikirim, hanya untuk situs link itu, dan hanya dikirim ke aplikasi di komputer ini. Di sisi aplikasi, cookie tidak ditulis ke disk.

Status Izin:

Ambil Alih Download Browser

Teruskan unduhan yang dimulai browser ke Download Engine

Menu klik-kanan hanya melihat href sebuah link, dan di banyak situs itu bukan yang benar-benar diunduh. Tombol unduh yang men-submit form dan halaman perantara menghasilkan URL lain — URL finalnya baru diketahui setelah browser menelusuri semua pengalihan.

Izin downloads memperlihatkan seluruh unduhanmu ke extension ini. Biarkan mati kalau menu klik-kanan sudah cukup.

Kirim dulu, batalkan belakangan: kalau aplikasi sedang tutup, bridge mati, atau token salah, download tidak dibatalkan — browser tetap menyelesaikannya.
Status Intersepsi:

Tanya Dulu Sebelum Mengambil Alih

Tampilkan dialog konfirmasi tiap kali sebuah unduhan ditangkap

Unduhan browser dijeda dulu, lalu popup extension terbuka sendiri di bawah ikon toolbar, berisi nama berkas, ukuran, dan alamat asalnya. Pilih Unduh dengan Engine untuk menyerahkannya, atau Biarkan Browser untuk melanjutkannya seperti biasa.

Mengklik di luar popup tanpa memilih sama dengan memilih browser — unduhannya dilanjutkan, tidak ada yang hilang.

Mematikannya berarti unduhan berpindah ke Download Engine tanpa pemberitahuan — baris unduhan di browser akan hilang begitu saja.
